== Purpose

This root document exists so humans and bots can see the hard audit posture
without having to discover the standards repository first.

Canonical source documents live in the `metadatastician/standards` repository.
This file is a repo-local audit gate summary for this repository and automated
agents.

== Hard Rules

* Do not call anything `stable`, `v1.0.0`, or full release unless the stable
  release gate has been passed end to end.
* Do not publish implementation-facing work below `B` in CRG unless the work is
  genuinely abstract and makes no implementation-readiness claim.
* `D` requires RSR compliance or a documented equivalent repository discipline.
* `C` requires deep code and folder annotation, not just local confidence.
* `B` means `beta-stable`: external breadth and safe broad trial, not merely
  public visibility.
* Papers, whitepapers, release notes, and READMEs must not outrun the proofs,
  tests, or artefacts that support their claims.
* Release paths must not ship with placeholders, stubs, `FIXME`, `XXX`,
  template residue, fake fuzz, fake benches, or partial proof debt hidden as
  if it were complete.

== Repository-Specific Audit Notes

* *Proved & CI-verified core:* The SPARK classifier kernel (`core-spark/`) is
  proved pure, total, and postcondition-conforming by `gnatprove` (`--level=2
  --report=all`), the Idris2 ABI (`abi-idris2/`) totality-checks discriminant
  round-trips and spec properties, the Zig FFI seam (`ffi-zig/`) runs
  exhaustive 27-state property tests, and the Rust host (`host-rust/`) runs
  exhaustive 27-state differential tests over the C ABI against
  `libsentinel_core.a` in CI (`.github/workflows/rust-ci.yml`).
* *Partially field-validated Windows collectors (`2026-07-02`):* Live `reg.exe`
  `RunAsPPL` output and the UTF-16LE `C:\ProgramData\0patch\Logs\0patch.log`
  format were validated on a real Windows host (`RunAsPPL=0x1`) with a licensed
  0patch agent installed; the speculative `0patchConsole.exe list-patches` CLI
  was removed (see link:docs/FIELD-VALIDATION.adoc[docs/FIELD-VALIDATION.adoc]).
* *Fail-closed right-censorship invariant:* Because `0patch.log` only records
  applied patches, `parse_opatch_log` returns `Unknown` (`INDETERMINATE`, exit
  `1`) whenever `loader != Loaded` and no `lsass.exe` application line is
  present, preventing a false `MOOT` (exit `0`) on protected hosts.
* *Still unverified live:* A live `Present` (`BLOCKED-INERT`, exit `2`) trigger
  on Windows, a positive CodeIntegrity `3033`/`3063` loader-block match, an
  unblocked local 0patch catalog source independent of `0patch.log`, and an
  end-to-end `installer/Install-LsaSentinel.ps1` scheduled-task run. See
  link:AFFIRMATION.adoc[AFFIRMATION.adoc] for the dated honesty snapshot and
  `audits/audit-residuals.adoc` for accepted structural residuals.
